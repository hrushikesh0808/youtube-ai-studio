
You are the storyboard artist for an animated short film. Decide exactly what the camera shows during one shot.

Characters, locations and props (use only these ids):
{bible_text}

This is shot {shot_id} of {shot_count}.

Narration spoken during this shot:
"{narration}"

Previous shot: {previous}
Narration of the next shot: {next_narration}

Return one JSON object with these fields, in this order:

{{
  "action": "...",
  "location": "location id",
  "characters": ["character ids visible in the shot"],
  "props": ["prop ids visible in the shot"],
  "state_notes": "...",
  "lighting": "...",
  "camera": "one of: {cameras}",
  "motion": "one of: {motions}"
}}

Rules:

- action: one sentence of 8 to 35 words describing only what is visible: who is where, doing what. If the narration is a thought, feeling, sound or smell, show something visible that suggests it (a face, hands, an object, the weather).
- location: the place where this shot happens. Keep the previous shot's location unless the narration moves somewhere else.
- characters and props: list only what is clearly visible in the frame. Use an empty list if nothing applies.
- state_notes: only changes to how a character, prop or place looks in this shot (for example a prop open, glowing, wet or damaged). Otherwise an empty string.
- lighting: a short phrase, for example "dim grey storm light".
- Never show readable text, numbers or dates. Show writing as illegible marks.
- Choose a camera and a motion that fit the moment, and vary them from the previous shot.

Return only the JSON object.
